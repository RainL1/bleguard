Подробное описание

Разбирает файлы захвата Bluetooth (BTSnoop и PCAP).

Читает HCI-фреймы из файла и извлекает данные BLE-соединения, параметры сопряжения SMP и информацию о ключах шифрования.

Поддерживаемые форматы:

  • BTSnoop (RFC 1761 / Android btsnoop_hci.log)
  • PCAP (libpcap, прямой и обратный порядок байт)
